## 📌 Sobre o Projeto
A **Calculadora de Consumo Elétrico Inteligente** é uma ferramenta desenvolvida em Python para ajudar usuários a estimarem o consumo de energia elétrica de seus eletrodomésticos e o custo aproximado na fatura mensal.

---

## 🧮 Fórmula Utilizada

O cálculo do consumo mensal utiliza a seguinte lógica matemática:

$$\text{Consumo Mensal (kWh)} = \frac{\text{Potência (W)} \times \text{Horas/Dia} \times 30}{1000}$$

Para o cálculo financeiro, considera-se uma tarifa estimada de **R$ 0,75 por kWh**:

$$\text{Custo Estimado (R\$)} = \text{Consumo Mensal (kWh)} \times 0.75$$
